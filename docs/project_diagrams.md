## 3. 完整任务执行流程图

```
┌─────────────────────────────────────────────────────────────────────────────┐
│                         任务执行完整流程                                      │
└─────────────────────────────────────────────────────────────────────────────┘

用户输入: "在小红书搜索火锅店，然后用微信分享给朋友"
     │
     ▼
┌─────────────────────────────────────────────────────────────────────────────┐
│ 步骤 1: Orchestrator Agent 接收任务                                          │
│ ┌─────────────────────────────────────────────────────────────────────────┐ │
│ │  orchestrator_agent.print_response(task, stream=True)                   │ │
│ └─────────────────────────────────────────────────────────────────────────┘ │
└─────────────────────────────────────────────────────────────────────────────┘
     │
     ▼
┌─────────────────────────────────────────────────────────────────────────────┐
│ 步骤 2: DashScope (qwen-plus) 分析任务                                       │
│ ┌─────────────────────────────────────────────────────────────────────────┐ │
│ │  🧠 AI 思考:                                                             │ │
│ │  - 理解用户意图                                                          │ │
│ │  - 识别关键步骤:                                                         │ │
│ │    1️⃣  打开小红书                                                        │ │
│ │    2️⃣  搜索"火锅店"                                                      │ │
│ │    3️⃣  查看并记录信息                                                    │ │
│ │    4️⃣  打开微信                                                          │ │
│ │    5️⃣  分享给朋友                                                        │ │
│ │                                                                          │ │
│ │  💡 决策: 调用工具 run_phone_task                                        │ │
│ └─────────────────────────────────────────────────────────────────────────┘ │
└─────────────────────────────────────────────────────────────────────────────┘
     │
     ▼ 调用: run_phone_task("打开小红书搜索火锅店")
┌─────────────────────────────────────────────────────────────────────────────┐
│ 步骤 3: AutoGLMTools 转发请求                                                │
│ ┌─────────────────────────────────────────────────────────────────────────┐ │
│ │  tools.run_phone_task(task_description)                                 │ │
│ │      ↓                                                                   │ │
│ │  phone_agent.run(task_description)                                      │ │
│ └─────────────────────────────────────────────────────────────────────────┘ │
└─────────────────────────────────────────────────────────────────────────────┘
     │
     ▼
┌─────────────────────────────────────────────────────────────────────────────┐
│ 步骤 4: PhoneAgent 执行循环                                                  │
│ ┌─────────────────────────────────────────────────────────────────────────┐ │
│ │  🔄 执行循环 (最多 100 步)                                               │ │
│ │                                                                          │ │
│ │  ┌────────────────────────────────────────────────────────────────────┐ │ │
│ │  │ 4.1 📸 截图采集                                                     │ │ │
│ │  │     adb shell screencap -p                                         │ │ │
│ │  │     → base64_image                                                 │ │ │
│ │  └────────────────────────────────────────────────────────────────────┘ │ │
│ │           ▼                                                              │ │
│ │  ┌────────────────────────────────────────────────────────────────────┐ │ │
│ │  │ 4.2 🧠 VLM 分析 (AutoGLM-Phone-9B)                                 │ │ │
│ │  │     输入: [系统提示, 任务描述, 截图, 屏幕信息]                      │ │ │
│ │  │     输出:                                                           │ │ │
│ │  │     <think>                                                         │ │ │
│ │  │       当前在桌面，需要启动小红书应用...                             │ │ │
│ │  │     </think>                                                        │ │ │
│ │  │     <answer>                                                        │ │ │
│ │  │       do(action="Launch", app="小红书")                             │ │ │
│ │  │     </answer>                                                       │ │ │
│ │  └────────────────────────────────────────────────────────────────────┘ │ │
│ │           ▼                                                              │ │
│ │  ┌────────────────────────────────────────────────────────────────────┐ │ │
│ │  │ 4.3 🔍 解析操作                                                     │ │ │
│ │  │     parse_action(response)                                         │ │ │
│ │  │     → {                                                            │ │ │
│ │  │         "_metadata": "do",                                         │ │ │
│ │  │         "action": "Launch",                                        │ │ │
│ │  │         "app": "小红书"                                             │ │ │
│ │  │       }                                                            │ │ │
│ │  └────────────────────────────────────────────────────────────────────┘ │ │
│ │           ▼                                                              │ │
│ │  ┌────────────────────────────────────────────────────────────────────┐ │ │
│ │  │ 4.4 ⚡ 执行操作 (ActionHandler)                                     │ │ │
│ │  │     adb shell am start -n com.xingin.xhs/.activity.SplashActivity │ │ │
│ │  │     → 启动小红书成功                                                │ │ │
│ │  └────────────────────────────────────────────────────────────────────┘ │ │
│ │           ▼                                                              │ │
│ │  ┌────────────────────────────────────────────────────────────────────┐ │ │
│ │  │ 4.5 ✅ 检查完成状态                                                 │ │ │
│ │  │     action._metadata == "finish" ?                                 │ │ │
│ │  │     → No, 继续下一步                                                │ │ │
│ │  └────────────────────────────────────────────────────────────────────┘ │ │
│ │           │                                                              │ │
│ │           └──────────────────────────────────────────────────────────────┤ │
│ │                                                                          │ │
│ │  [重复 4.1-4.5 直到任务完成或达到最大步数]                               │ │
│ └─────────────────────────────────────────────────────────────────────────┘ │
└─────────────────────────────────────────────────────────────────────────────┘
     │
     ▼ 返回: "已在小红书搜索到火锅店信息"
┌─────────────────────────────────────────────────────────────────────────────┐
│ 步骤 5: Orchestrator 处理结果并继续                                          │
│ ┌─────────────────────────────────────────────────────────────────────────┐ │
│ │  📊 分析子任务结果                                                       │ │
│ │  ✅ 第一个子任务完成                                                     │ │
│ │  🔄 继续下一个子任务: run_phone_task("打开微信分享给朋友")               │ │
│ └─────────────────────────────────────────────────────────────────────────┘ │
└─────────────────────────────────────────────────────────────────────────────┘
     │
     ▼ [重复步骤 3-5 直到所有子任务完成]
┌─────────────────────────────────────────────────────────────────────────────┐
│ 步骤 6: 返回最终结果                                                         │
│ ┌─────────────────────────────────────────────────────────────────────────┐ │
│ │  🎉 任务完成!                                                            │ │
│ │  "已在小红书找到火锅店信息并通过微信分享给朋友"                           │ │
│ └─────────────────────────────────────────────────────────────────────────┘ │
└─────────────────────────────────────────────────────────────────────────────┘
```
