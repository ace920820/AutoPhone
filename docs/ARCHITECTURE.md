## 系统概述

AutoPhone 是一个基于 AI 的智能手机自动化系统，能够理解自然语言指令并在 Android 设备上执行复杂的跨应用任务。

### 核心特性

- 🤖 **双层 Agent 架构** - Orchestrator 负责任务分解，PhoneAgent 负责执行
- 👁️ **视觉理解** - 基于 VLM (Vision Language Model) 理解屏幕内容
- 📱 **ADB 控制** - 通过 Android Debug Bridge 控制真实设备
- 🔗 **Agno 框架集成** - 利用 Agno 实现工具调用和对话管理
- 📊 **执行跟踪** - 详细记录每个步骤，生成可视化报告

## 核心组件

### 1. Orchestrator Agent (编排 Agent)

**位置**: `phone_agent/registry.py`

**职责**:
- 接收用户的复杂任务请求
- 将任务分解为可执行的子步骤
- 调用 `run_phone_task` 工具执行子任务
- 根据执行结果调整计划
- 汇总并返回最终结果

**Agno 组件**:
```python
from agno.agent import Agent
from agno.models.dashscope import DashScope
from agno.db.sqlite import SqliteDb

orchestrator_agent = Agent(
    id="phone-orchestrator",
    name="手机任务编排专家",
    model=DashScope(id="qwen-plus"),
    tools=[AutoGLMTools(...)],
    db=SqliteDb(...),  # 会话存储
    add_history_to_context=True,  # 上下文记忆
)
```

### 2. AutoGLMTools (工具桥接)

**位置**: `phone_agent/tools.py`

**职责**:
- 作为 Agno Toolkit，注册 `run_phone_task` 方法
- 将 Orchestrator 的调用转发给 PhoneAgent
- 管理 PhoneAgent 的生命周期

```python
class AutoGLMTools(Toolkit):
    def run_phone_task(self, task_description: str) -> str:
        """在手机上执行指定任务"""
        self.phone_agent.reset()
        return self.phone_agent.run(task_description)
```

### 3. PhoneAgent (执行 Agent)

**位置**: `phone_agent/agent.py`

**职责**:
- 执行具体的手机操作任务
- 管理截图-分析-执行循环
- 调用 VLM 模型理解屏幕
- 执行 ADB 操作命令

```python
class PhoneAgent:
    def run(self, task: str) -> str:
        while not finished and step < max_steps:
            screenshot = get_screenshot()
            response = self.model_client.request(context)
            action = parse_action(response)
            result = self.action_handler.execute(action)
```

### 4. ADB 工具集

**位置**: `phone_agent/adb/`

| 模块 | 功能 |
|------|------|
| `screenshot.py` | 设备截图采集 |
| `input.py` | 文本输入（支持中文） |
| `device.py` | 点击、滑动、返回、主页 |
| `connection.py` | 设备连接管理 |

数据类型说明:
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
用户输入      →  str (自然语言任务描述)
DashScope    →  ChatCompletion (流式响应)
Tool Call    →  dict {name, arguments}
VLM 输入     →  list[Message] (含 base64 图像)
VLM 输出     →  str (<think>...</think><answer>...</answer>)
Action       →  dict {_metadata, action, element, ...}

## 日志与跟踪

### 日志系统

**配置文件**: `phone_agent/logging_config.py`

```python
from phone_agent.logging_config import get_logger, setup_logging

# 初始化日志系统
setup_logging(level=logging.INFO)

# 获取日志器
logger = get_logger("my_module")

# 使用日志
logger.info("开始执行任务")
logger.debug("调试信息")
logger.error("错误信息", exc_info=True)
```

**日志输出**:
- 控制台: 彩色格式化输出
- 文件: `logs/phone_agent_YYYYMMDD.log`
- JSON: `logs/phone_agent_YYYYMMDD.json`

### 执行跟踪

**配置文件**: `phone_agent/tracing.py`

```python
from phone_agent.tracing import ExecutionTracer

# 创建跟踪器
tracer = ExecutionTracer("搜索火锅店")
tracer.start()

# 记录步骤
tracer.add_step(
    screenshot_base64=screenshot,
    current_app="小红书",
    thinking="分析屏幕内容...",
    action={"action": "Tap", "element": [500, 200]},
    action_result="点击成功",
    success=True
)

# 完成并保存报告
tracer.finish("任务完成")
report_path = tracer.save_html_report()  # traces/trace_xxx.html
```

**跟踪报告**: 
- HTML 可视化报告，包含每一步的截图、思考过程、操作和结果
- JSON 数据导出，便于程序分析
